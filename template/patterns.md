## 1. 高速入出力（これだけは毎回やる）

Python は `input()` と `print()` をそのまま大量に呼ぶと、それだけで TLE する。

```python
import sys
input = sys.stdin.readline   # 入力を速くする（行末に \n が残るので rstrip すること）

out = []
# ... 処理して out.append(answer) ...
print("\n".join(out))        # 出力は最後に1回だけ
```

- `T ≤ 3×10^5` のようにケース数が多い問題で特に効く。
- 文字列を読むときは `input().rstrip()` で改行を除去する。
- `int(input())`、`map(int, input().split())` も readline 版なら速い。

## 2. 「全マスから1個ずつ取り除く」を仮想化する（実際に配列を書き換えない）

操作を実際にやると O(N)。代わりに「これまで何回引いたか」を変数 `k` で持ち、
本当の値 = `累計 - k` として扱うと O(1) になる。

- 削除回数 `k` は「累計の最小値」に一致することが多い。
- 判定や出力では `しきい値 + k` のように `k` を足してオフセットする。

→ 「全体に一律の加減算」が来たら、配列を触らず変数1個で表せないか考える。

## 3. 「ある値 v 以上の個数」を O(1) で持つ（BIT 不要バージョン）

「ちょうど v 個」の頻度 `freq[v]` だと "以上" を求めるのに区間和（BIT）が要る。
代わりに **最初から「v 以上の個数」** を持つと、1点更新だけで済むことがある。

```python
at = [0] * (上限 + 1)        # at[v] = 値が v 以上の要素の個数
# ある要素を old -> old+1 に増やすとき、変化するのは at[old+1] だけ（+1）
at[old + 1] += 1
# 「v 以上の個数」を聞かれたら at[v] を返す（v が上限超なら 0）
```

→ 更新が「+1 ずつ」なら、"以上カウント" は1点更新で追える。配列サイズは制約の上限+1で確保。

## 4. 種類が少ないものは「種類数」だけソートする

英小文字なら 26 種類。要素が 10^6 個あっても、ソートするのは 26 個の
`(回数, 文字)` ペアだけでよい。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - ord("a")] += 1
pairs = [(cnt[i], chr(ord("a") + i)) for i in range(26) if cnt[i] > 0]
pairs.sort(reverse=True)     # 多い順
```

## 5. 「隣り合う2文字を別にする再配置」＝ 1個飛ばし配置

- **可否判定**: 最頻文字の個数 `maxcount` が `(N + 1) // 2`（= 偶数マスの数）以下なら可能。
- **構築**: 多い順に、位置 `0,2,4,…,1,3,5,…` の順で詰める。インデックス折り返しテク:

```python
result = [None] * n
idx = 0
for count, ch in pairs:       # 多い順
    for _ in range(count):
        result[idx] = ch
        idx += 2
        if idx >= n:
            idx = 1
ans = "".join(result)
```

理由: 最頻文字が偶数マス（2マス間隔）に収まれば隣接しない。残りも芋づる式に安全。

## 6. 内包表記 `[...]` と ジェネレータ式 `(...)` の違い（ハマりやすい）

```python
p = [(x, y) for ...]      # ← リスト。p[0] でアクセスできる
p = [((x, y) for ...)]    # ← リストの中にジェネレータが1個。要素にアクセスできない！
```

`[]` の中をさらに `()` で囲むとジェネレータ式になる。内包表記は `[]` の直後に式を書く。

## 7. 配列サイズと添字のオフバイワン

添字 `Q` までアクセスするなら配列サイズは `Q + 1`（添字 0..Q で計 Q+1 個）。
制約に上限があるなら「上限 + 少し」で固定確保するのも実戦的（ただし制約を超えないこと）。
